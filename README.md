# 🪟 ガラス耐風圧 簡易検討ツール

**4辺支持ガラスの風圧検討・最小構成自動選定ツール（ブラウザ単体動作）**

## 概要

ガラスの幅・高さ・設置階数・部位を入力するだけで、設計風圧に対して成立する**最小板厚のガラス構成を自動選定**し、計算根拠を一画面で確認できる簡易ツールです。

HTML / CSS / JavaScript のみで構成された **1ファイル完結型**のため、外部サーバーやライブラリのインストール不要。GitHub Pages にホストすることで、ブラウザさえあればどこからでも利用できます。

---

## 機能

- 設計風圧の自動判定（正圧 vs 負圧の大きい方を採用）
- 対応ガラス構成：
  - 複層ガラス：Low-E + A + FL
  - 複層ガラス：FL + A + FL
  - 単板ガラス：FL
  - 単板ガラス：TP（強化ガラス）
- 最小構成の自動選定（最大板厚昇順 → 合計板厚昇順）
- 複層ガラスの外側・内側それぞれの許容風圧計算と支配側の明示
- 候補一覧（上位10件）の表形式表示
- 補正係数をスライダーで調整（0.70 〜 1.00）
- レスポンシブ対応（PC・タブレット・スマートフォン）

## 入力項目

| 項目 | 説明 | 初期値 |
|------|------|--------|
| ガラス幅 W | mm単位で入力 | 1250 mm |
| ガラス高さ H | mm単位で入力 | 2050 mm |
| 設置階数 | 1階 / 2階 / 3階 / R階 | 2階 |
| 部位 | 一般部 / 隅角部 | 一般部 |
| 候補ガラス構成 | 複層/単板・ガラス種別 | Low-E + A + FL |
| 補正係数 | 0.70 〜 1.00（スライダー） | 0.90 |

## 設計定数

### 設計風圧（正圧）

| 階数 | 正圧 N/m² |
|------|----------:|
| 1階  | 1,297 |
| 2階  | 1,525 |
| 3階  | 1,695 |
| R階  | 1,729 |

### 設計風圧（負圧）

| 部位   | 負圧 N/m²（絶対値） |
|--------|-------------------:|
| 一般部 | 918 |
| 隅角部 | 1,122 |

### k1：ガラス種別係数（FL / Low-E 系）

| 板厚 t | k1 |
|--------|----|
| t ≦ 8mm | 1.0 |
| 8mm < t ≦ 12mm | 0.9 |
| 12mm < t ≦ 20mm | 0.8 |
| 20mm < t | 0.75 |

- TP（強化ガラス）：k1 = 3.5
- Low-E は FL 相当として扱う

---

## 計算式

### 許容風圧（4辺支持）

```
P = (300 × k1 × k2 / A) × t² × 補正係数
```

- `A`：ガラス面積 [m²] = W × H / 1,000,000
- `t`：板厚 [mm]
- 設計風圧 = max(正圧, |負圧|)

### 複層ガラスの k2

```
k2_outer = 0.75 × { 1 + (t_inner / t_outer)³ }
k2_inner = 0.75 × { 1 + (t_outer / t_inner)³ }
厚さ比の上限 = 2.0
P_IGU = min(P_outer, P_inner)
```
